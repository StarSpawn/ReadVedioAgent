# 验收

识别阶段只给视频和 standards/，生成工程后再对照此目录。word-reference.json 是按 v2 口径整理的部分事件，时间取自试标和全片工程，供定位复核。按事件含义匹配，分别检查轨道、漏标、多标与时间差异。

- 开头：填「喜」的引导与示范合成一条教程。首次连击反馈是独立玩法事件。结算拼图记局外系统，启动进度条记加载。
- 约 39.5 秒：提示道具首次展示自动填字功能，记局内玩法；约 41 秒的使用手势记教程。
- 全片关卡轨：每个可辨认关号只有一条，正文形如“第2关”。约 134 秒和 326 秒的困难提示不能新增关卡标记，按玩法或系统是否发生变化决定收录。

- 第 34 关至后续结算：约 487.5 秒的体力补给和约 572 秒的双倍提示分别是激励入口。约 490 秒播放和约 506 秒结束都不生成 IAA 标记。广告返回后的无限体力可作为独立的跨关资源状态记录。

跨游戏复验使用圆环解谜：开头检查手势、解环机制、下一关及宝箱进度；第 10 关清盘后检查全屏插屏，结算后再检查双倍领取入口。相邻两条广告素材可属于同一次插屏展示。只看见奖励按钮不能推断观看了激励视频。
