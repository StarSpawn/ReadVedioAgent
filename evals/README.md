# 验收

识别阶段只给视频和 standards/，生成工程后再对照此目录。word-reference.json 来自已确认的五轨试标工程，记录原标记的位置和文字，未逐帧校准。不要按标记数机械评分。

按事件含义匹配，再逐条检查轨道、漏标、多标与时间差异。0–20 秒检查填字机制、手势教程、结算拼图、第 1 和第 2 关以及启动加载。483–509 秒检查第 34 关、体力不足入口、激励广告实际展示和返回后的奖励。启动加载是四轨历史工程未覆盖的事件。

已校准一处旧答案：第 34 关广告在 489.625 秒的采样仍只有游戏弹窗，489.750 秒的采样已能看到广告素材和奖励倒计时。以这一区间为边界依据，覆盖旧标记 490.30 秒。记录抽样步长，避免把采样时间当作精确帧时间。

跨游戏复验使用圆环解谜：开头检查手势、解环机制、下一关及宝箱进度；第 10 关清盘后检查全屏插屏，结算后再检查双倍领取入口。相邻两条广告素材可属于同一次插屏展示。只看见奖励按钮不能推断观看了激励视频。
