# 移动端超休五轨 v1

使用下列顺序。标记时间为事件在原视频中首次可辨认的片内秒数。同一时间允许有不同轨道的独立观察。

|轨道|记录口径|
|---|---|
|局内玩法|首次出现的机制、操作规则、表现反馈或玩法变化。相同操作只在发生有意义的变化时再标。|
|局外系统|拼图、宝箱、体力、收藏等跨关进度与解锁。按功能归类，结算页和关内弹层都可能包含这些系统。|
|关卡|关号与开始时间，取该关画面首次可辨认处。录屏中途开始则写“录屏开始时已在第 N 关”；不可辨认则写“关号待确认”。重试注明重试。|
|IAA|记录广告点位、类型、触发场景。激励视频入口和实际播放分别标；只看到入口则只标入口。插屏、横幅等注明可见类型和位置。|
|加载及教程|前缀使用“加载开始”“加载结束”或“教程”。加载要求有明确等待证据；教程写手势、高亮、提示文字和引导动作。机制与引导同现时可分别标在玩法和教程轨。|

已确认的边界：绿框提示填字与填字规则分别记入教程和玩法轨；补体力的广告入口和广告播放分别标记。实际展示取广告素材或广告倒计时首次可见的一刻，包括只从底部滑入一部分的情况。加载起止沿用上述暂定口径；启动页在录屏开始时已有进度条的，注明“录屏开始时已在加载”。
