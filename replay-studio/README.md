# 帧迹 · 游戏录屏研究台

面向游戏调研的录屏标注软件。视频在浏览器本地播放，研究内容和素材不会上传到服务器。应用没有运行时第三方依赖。

## 启动

Windows 双击 `启动帧迹.cmd`，会在后台启动服务并打开浏览器；或在此目录执行 `npm start` 后打开 http://127.0.0.1:4173 。需要 Node.js 20 或更新版本。应用本身也可静态托管。

Mac 解压后双击 `启动帧迹.command`，同样会启动本地服务并打开默认浏览器。需要预装 Node.js 20 或以上版本；入口支持官方安装路径和 Apple Silicon / Intel 的常用 Homebrew 路径。使用 nvm 等版本管理器时，也可以在已配置 Node.js 的终端中运行 `bash 启动帧迹.command`。

若解压工具未保留执行权限，在终端进入解压目录后运行 `chmod +x 启动帧迹.command`，再双击。若 macOS 提示无法打开，可先右键文件选择“打开”，或在该目录的终端执行 `bash 启动帧迹.command`。不需要关闭系统安全保护。

Mac 入口已做脚本语法、浏览器调用分支及包内权限检查；尚未做 Mac 实机验收。

## 工作流程

1. 导入一条或多条视频。拖动素材卡片或视频时间轴片段调整顺序，也可用素材卡片上的上下箭头。
2. 单击或拖动时间轴定位；空格播放/暂停；左右方向键按当前片段的 FPS 逐帧步进；Shift + 方向键跳转 5 秒。也可输入精确时间跳转。
3. 在时间轴左侧轨道列表上方添加轨道，设置名称和独立颜色。轨道菜单支持改名、换色、调整顺序和删除。
4. 按 M 或双击轨道，在对应时间记录观察。新标记点击“添加标记”创建，或按 Ctrl / Cmd + Enter。已有标记修改内容、时间或轨道后自动保存：停止输入约 0.6 秒或离开输入框时生效；支持撤销、删除、搜索和点击跳转。
5. 导出 Excel：设置从哪个时间起、每格多少秒。默认前 1 分钟每 10 秒、1–30 分钟每 1 分钟、30 分钟后每 10 分钟。支持更多分段及小数秒。
6. 保存 `.replay` 工程，下次打开继续工作。Ctrl / Cmd + S 打开保存选项。Ctrl / Cmd + Z 撤销，Ctrl / Cmd + Shift + Z 重做。

## 工程与视频

- **轻量工程**保存视频元数据、顺序、轨道、标记、分段规则，以及播放位置、选中轨道和时间轴缩放，不复制视频。恢复画面时选择同名、同大小、同时长的原始文件。
- **完整工程**包含原视频，可直接传给其他人继续工作。文件体积约等于原视频总和加标注数据。工程使用二进制分段封装，不把大视频转成 Base64；打开时以 Blob 切片读取。
- 浏览器自动备份研究元数据；刷新后点击“恢复进度”。备份不包含视频，清理站点数据会清除备份，因此正式交接请保存工程文件。
- 完整工程文件头：12 字节 `FRAMETRACE01`，4 字节小端 JSON 长度，UTF-8 JSON manifest，依次附加原视频二进制。manifest 包含 version=1 的 project 与媒体 offset/size/type 索引。

## 时间与导出口径

- 视频顺序连接成连续的总时间轴。标记绑定到“片段 ID + 片段内时间”，重排后自动重算总时间。
- 删除片段会同时移除关联标记，删除轨道会移除轨道内标记；操作前有提示，并支持撤销。
- Excel 时间格为左闭右开区间：10 秒进入 10–20 秒格；整个时间轴终点进入最后一格。不足一格的尾段保留。
- 同一格的多条标记全部保留并换行，每条附精确总时间。
- Excel 文件是标准 `.xlsx`，包含「时间轴标注」「标记明细」「导出说明」。冻结首行和首列，轨道名称按颜色填充。文本按字符串写入，不作为公式执行。
- 超过 Excel 的 16,383 个时间列或单格 32,767 字符限制时，界面提示调整粒度，不静默截断。

## 播放支持与边界

- 依赖浏览器的本地视频解码。推荐 H.264/AAC MP4 或 WebM；MOV/MKV 是否可用取决于内部编码及浏览器。
- 素材卡片可设置源视频 FPS，默认 30；支持如 29.97、59.94。恒定帧率视频按该步长定位；可变帧率视频是按时间近似步进，不承诺原始逐帧索引精确。这是浏览器播放器的实现边界。
- 本版本处理研究标注，不做视频裁剪、转码、合并输出或云端多人同时编辑。
- 浏览器保存完整工程时优先使用文件系统写入流；不支持该接口的浏览器使用下载。超大型工程建议先保存轻量文件并保留原视频。

## 验证

`npm test` 使用 Node 内置测试器，覆盖分段边界、片段重排、工程往返恢复、损坏文件和 XLSX 生成。

`tests/browser.mjs` 是本地端到端测试，需要 Playwright 与 Microsoft Edge，以及 `test-results/alpha.mp4`、`beta.mp4` 两个各 4 秒的测试视频。测试覆盖导入、轨道与标记、重排、播放跨片段、工程与 Excel 下载、恢复和重新关联。不录制屏幕。
